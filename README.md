# Node Injection Attacks on Graphs

Group project for the **Graph Mining and Social Networks** course. The project focuses on adversarial node injection attacks and the robustness of text-attributed graphs.

The project brief is available in [`doc/main.pdf`](doc/main.pdf), with its LaTeX source in [`doc/main.tex`](doc/main.tex).

## Building the document

From the `doc/` directory, with `latexmk` installed:

```sh
latexmk -pdf main.tex
```

LaTeX build artifacts are excluded from Git tracking.
